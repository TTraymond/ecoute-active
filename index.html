Comment écrire un script

Une réplique par ligne, qui commence par le nom de la personne puis « : ».

Titre : Appel d’un prospect
Niveau : 1re B
Contexte : Une phrase pour situer la scène.
Client : Bonjour, je cherche…
Vendeur [Reformulation] : Si je comprends bien…
? Quel est le budget ? = 250 | deux cent cinquante

Les rôles : « Vendeur », « Conseiller », « Commercial », « Négociateur », « Agent », « Chargé » ou « Élève » = le rôle de l’élève. Tous les autres noms (Client, Mme Kaci, Secrétaire…) = l’interlocuteur.

[Technique] après le nom : la technique d’écoute de la réplique, pour l’exercice « Repérer la technique ». Exemples : [Question ouverte] [Reformulation] [Empathie].

{étiquette:texte} dans une réplique : une information que l’élève doit noter. Exemple : {budget:cent vingt euros}. L’appli lit seulement « cent vingt euros ».

? question = réponse : une question de compréhension. Plusieurs réponses acceptées, séparées par |. Les majuscules et les accents ne comptent pas.

Écris les nombres en lettres dans les répliques (« seize heures trente ») : la voix les lit mieux.

Méthode

Les techniques d’écoute active

Écouter activement, c’est montrer au client qu’on l’a compris, et l’aider à dire ce dont il a vraiment besoin. Le vendeur parle peu, questionne, reformule et note.

Bien prendre des notes pendant un appel

  • Note des mots-clés, pas des phrases : « 3 pièces · gare · budget 250 k€ ».
  • Note les chiffres tels qu’ils sont dits : dates, heures, prix, quantités.
  • Fais répéter ou épeler un nom : « Pouvez-vous me l’épeler ? »
  • Termine toujours par une synthèse pour vérifier tes notes avec le client.
